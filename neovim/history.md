# 操作方法
(少し配置が変えてある)

## 移動
- k:up
- j:down
- h:left
- l:right
- gg: 一番上に戻る
- shift+g: 一番下に戻る

- shift + ] : カーソル位置の下にあるスペースに移動
- shift + [ : カーソル位置の上にあるスペースに移動

- zz: カーソル場所を画面の真ん中に持ってくる
- zb: カーソル場所を画面の最も下に持ってくる
- zt: カーソル場所を画面の最も上に持ってくる

- w 後ろのワードの頭に動く
- b 前のワードの頭に動く

- 0            行の最初
- $(shift + 4) 行の後ろ

## 使う機能

- u 戻る
- ctrl+r やり直し
- y ヤンク　(コピー)
- p ペースト
- yy 一行すべてコピー
- dd 一行すべて削除
- : 数字　上から数えたときの絶対値の行に飛ぶ

- dk カーソル位置から上の一画面分すべて削除
- dj カーソル位置から下の一画面分すべて削除

- shift + v 全範囲選択
- ctrl + v 範囲選択

- shift + ] 範囲選択のインテンデーション

- c + i + " ダブルクォーテーション内の文字をすべて消す

- c + a + "　ダブルクォーテーションまで消す

- v + i + " ダブルクォーテーション内の文字を範囲選択

- v + a + " ダブルクォーテーションまで選択

- ctrl + l 右のタブ*
- ctrl + h 左のタブ*



## モード

- Esc ノーマルモードに戻る
- i インサートモード(文字を入れられる)
- v ビジュアルモード(範囲選択モード)
- shift　+ : コマンドモード




## 編集

- sihft + :　　コマンドモード 
- w セーブ 
- wq そのウィンドウを閉じる
- !q 何があっても抜ける
- %s/1/2 1の単語を2に置換

- / 検索モード
- n 次の検索単語
- shift + n 前の検索単語
